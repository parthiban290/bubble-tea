🧋 Bubble Tea — Product Landing Page
A responsive product landing page developed using HTML5 and CSS3. The project focuses on creating an attractive product website with promotional sections, product cards, navigation, responsive layouts, CSS-based sliders, transitions, and custom animations.

🚀 Features
- Responsive landing page
- Hero section
- Navigation bar
- Product cards
- Promotional sections
- Call-to-action sections
- CSS-based product slider
- Hover effects
- CSS transitions
- Custom animations
- Responsive design for different screen sizes

🛠️ Technologies Used
- HTML5
- CSS3
- CSS Animations
- Responsive Web Design
- Google Fonts
- Font Awesome

🎨 UI Features
```
🏠 Hero Section
Designed an attractive hero section to introduce the bubble tea products with promotional content and call-to-action elements.
🧋 Product Cards
Created product cards to display different bubble tea products with images, names, and supporting information.
🎞️ CSS Slider
Implemented a CSS-based slider using selectors, transforms, and transitions without JavaScript.
✨ Animations & Transitions
Used CSS animations, hover effects, transforms, and transitions to create an interactive user interface.
📱 Responsive Design
Implemented responsive layouts using CSS media queries for different screen sizes.
```
